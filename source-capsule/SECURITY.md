# Security policy

This alpha prototype is not suitable for production assurance decisions.

Please report vulnerabilities privately through GitHub's security-advisory feature when available. Do not include secrets, private evaluation records, customer data, or exploit data that could harm others in a public issue.

The project currently provides no authentication, signer authorization, secret storage, sandboxing, network service, or protection against a malicious source. SHA-256 checks exact bytes only; it does not establish truth or authority.
